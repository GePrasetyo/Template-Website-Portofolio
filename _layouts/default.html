{%- comment -%} Page shell for every theme. Look & feel (_data/look.yml, edited through /admin) picks the theme, colours, fonts and light/dark mode. The theme draws the page body in _includes/themes//frame.html, which wraps {{ content }} in its header and footer. {%- endcomment -%} {%- assign look = site.data.look -%} {%- assign theme = site.data.themes[look.theme] -%} {%- comment -%} Colours: a preset's light and dark sets, or the custom ones. {%- endcomment -%} {%- assign palette = look.palette | default: 'theme' -%} {%- if palette == 'custom' and look.custom.background == nil -%}{%- assign palette = 'theme' -%}{%- endif -%} {%- if palette == 'theme' -%}{%- assign palette = theme.palette -%}{%- endif -%} {%- if palette == 'custom' -%} {%- assign look_main = look.custom -%} {%- assign look_dark = look.custom_dark -%} {%- capture main_brightness %}{% include brightness.html hex=look_main.background %}{% endcapture -%} {%- assign main_brightness = main_brightness | strip | plus: 0 -%} {%- if main_brightness < 128 %}{% assign main_dark = true %}{% else %}{% assign main_dark = false %}{% endif -%} {%- else -%} {%- assign look_main = site.data.palettes[palette].light -%} {%- assign look_dark = site.data.palettes[palette].dark -%} {%- assign main_dark = false -%} {%- endif -%} {%- comment -%} Light and dark: "auto" follows the visitor's device and shows a switch, "light" and "dark" fix one set.
